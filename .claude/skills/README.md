# Project skills

Skills die hier staan zijn beschikbaar voor iedereen die deze repo met
Claude Code opent (in tegenstelling tot persoonlijke skills onder
`~/.claude/skills/` op je eigen machine, die niet meegecomit worden).

Een skill is een map met minimaal een `SKILL.md`:

```
.claude/skills/<skill-naam>/
  SKILL.md
  (optioneel: extra bestanden, scripts, assets)
```

Skill toevoegen: kopieer de map van `~/.claude/skills/<skill-naam>/`
hierheen en commit.
